# Lab 15 — Secure mini toolkit

## Purpose

Compose small **defensive helpers**: bounded string copy (`strlcpy`), structured logging with `snprintf`, and simple configuration objects.

## Concept

Security posture improves when reusable helpers encode **policy** (caps, truncation) once.

## Commands

```sh
cd labs/15-secure-mini-toolkit
make run
make analyze
```

## Security scope

Educational composition patterns for larger services.
